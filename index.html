팀 공유 자료실

GOOGLE DRIVE / hd_프로젝트

HD 프로젝트에 필요한 초안, 참고 자료, 최종 파일을 주고받는 공간입니다.

Google Drive / hd_프로젝트
  1. 올리기 — 폴더 열기 → + 새로 만들기 → 파일 업로드
    또는 열린 Drive 폴더에 파일을 끌어다 놓으세요.
  2. 받기 — 파일 선택 → 마우스 오른쪽 버튼 → 다운로드
  3. 파일명 권장 — HD_자료명_YYYYMMDD_v01
Drive에서 업로드 (새 탭)파일 받기 (새 탭)
두 버튼 모두 지정된 폴더를 엽니다. 업로드는 폴더 편집 권한, 다운로드는 소유자가 허용한 권한이 필요합니다.

우리 팀 사용 가이드

먼저 읽어 주세요
01 / ACCESS

30명에게 문서·폴더 공유하기

관리자가 Google 문서와 폴더의 ‘공유’에서 팀원 또는 Google 그룹을 추가해 주세요. 사이트를 열 수 있어도 Drive 권한은 별도로 필요합니다.

02 / UPDATE

일정 수정은 이 브라우저에 저장

업무명이나 막대를 눌러 날짜·담당자·진행률을 수정하세요. 현재는 예시로 시작하며, 수정 내용은 다른 팀원에게 자동 동기화되지 않습니다.

03 / SHARE

관리자가 최신 버전 공유하기

‘공유용 HTML 저장’으로 현재 일정이 담긴 파일을 받아 GitHub의 index.html을 교체하세요. 또는 일정 JSON을 자료실에 올리고 팀원이 가져올 수 있습니다.
